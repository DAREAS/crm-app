# CRM App (Mobile)

Cross-platform CRM mobile app (React Native) for managing clients, tasks, and reminders, with local and WhatsApp notifications integration.

## Features
- User registration and login
- Profiles: Free, Premium, Premium AI
- Client management
- Task management linked to clients
- Reminder management with local and WhatsApp notifications
- Editable user profile

## How to run
1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the app:
   ```sh
   npx expo start
   ```
   or
   ```sh
   npx react-native run-android
   ```

## Configuration
- Change `API_URL` in `App.js` to your backend address.
- For WhatsApp notifications, register your number in Twilio's sandbox.
